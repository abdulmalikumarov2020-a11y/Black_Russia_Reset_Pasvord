## Привет, мир!

Это первый пост в моём новом блоге, собранном на **Next.js 14 (App Router)**,
**TypeScript** и **Tailwind CSS**. Контент хранится в обычных `.mdx`-файлах —
это удобно: пишешь Markdown, а при необходимости вставляешь React-компоненты.

### Что умеет этот блог

- Статическая генерация страниц (SSG) — быстрая загрузка и хороший SEO
- Подсветка синтаксиса в блоках кода
- Тёмная и светлая тема с сохранением выбора в `localStorage`
- Категории (теги) и поиск по заголовкам постов

Пример блока кода с подсветкой синтаксиса:

```ts
function greet(name: string): string {
  return `Привет, ${name}!`
}

console.log(greet('читатель'))
```
